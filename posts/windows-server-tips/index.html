Windows Server Tips ที่ใช้บ่อยในงาน IT

รวม Tips การใช้งาน Windows Server ที่ช่วยประหยัดเวลาในงานประจำวัน

ในฐานะ IT ที่ต้องดูแล Windows Server อยู่ทุกวัน มีหลายคำสั่งและเทคนิคที่ช่วยประหยัดเวลาได้มาก วันนี้เลยรวบรวมมาฝากครับ

1. เช็ค Event Log ด่วนด้วย PowerShell แทนที่จะเปิด Event Viewer ที่ช้า ใช้คำสั่งนี้ได้เลย Get-EventLog -LogName System -Newest 20 -EntryType Error กรองเฉพาะ Error ล่าสุด 20 รายการ เห็นปัญหาได้ทันที

2. เช็ค Disk Space ทุก Drive Get-PSDrive -PSProvider FileSystem | Select-Object Name, Used, Free ดู disk ทุก drive พร้อมกันในครั้งเดียว ไม่ต้องคลิกทีละอัน

3. Restart Service ที่ค้าง Restart-Service -Name "ชื่อ Service" -Force ใช้ -Force เพื่อบังคับ restart แม้ service จะค้างอยู่

4. เช็ค Port ที่เปิดอยู่ netstat -ano | findstr "LISTENING" ดูได้ว่า port ไหนเปิดอยู่ และ Process ID คืออะไร

5. Remote ไปเครื่องอื่นด้วย PowerShell Enter-PSSession -ComputerName SERVERNAME -Credential (Get-Credential) เหมือน SSH แต่เป็น Windows style — สะดวกมากเวลาต้องจัดการหลายเครื่อง

6. ดู User ที่ Login อยู่ query user /server:SERVERNAME เช็คได้เลยว่าใคร login อยู่บน server ตัวไหน

7. Clear DNS Cache Clear-DnsClientCache เวลา DNS มีปัญหา ลองคำสั่งนี้ก่อนเลย แก้ได้หลายเคสมาก

สรุป คำสั่ง PowerShell เหล่านี้ช่วยให้งาน Windows Server Admin ง่ายขึ้นมากครับ ไม่ต้องคลิกผ่าน GUI ให้เสียเวลา ลองนำไปใช้ดูได้เลย! หากมีคำสั่งไหนที่ใช้บ่อยเพิ่มเติม comment ไว้ได้เลยนะครับ 😊

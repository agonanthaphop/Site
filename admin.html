ตั้งค่าการบันทึกขึ้น GitHub

ปุ่ม "บันทึกขึ้น GitHub" จะ commit ไฟล์ data.json เข้า repository โดยตรง แล้ว GitHub Pages จะอัปเดตหน้าเว็บภายในประมาณ 1 นาที

วิธีสร้าง token: GitHub → Settings → Developer settings → Personal access tokens → Fine-grained tokens → Generate new token
• Repository access: Only select repositories แล้วเลือก repo ของเว็บนี้เท่านั้น
• Permissions → Repository permissions → Contents: Read and write
• ตั้งวันหมดอายุตามความเหมาะสม และอย่าแชร์ token ให้ผู้อื่น

เปลี่ยนรหัสผ่านหน้าจัดการ

รหัสผ่านถูกเก็บเป็นค่า hash (PBKDF2-SHA256) ใน data.json ไม่เก็บตัวรหัสจริง หลังเปลี่ยนแล้วต้องกด "บันทึกขึ้น GitHub" ด้วย
